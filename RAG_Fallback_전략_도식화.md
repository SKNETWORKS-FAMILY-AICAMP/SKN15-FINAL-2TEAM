# RAG Fallback 전략 도식화

> RAG 검색 결과가 없을 때 다단계 검색 전략
>
> 작성일: 2025년 11월 7일

---

## 문제: RAG 데이터베이스가 비어있거나 결과가 없을 때?

초기 상태에서는 `TripCourseEmbedding` 테이블이 비어있습니다.
이때 사용자가 "여행지 추천해줘"라고 하면 아무 결과도 나오지 않습니다!

## 해결책: **다단계 Fallback 전략** ⭐

---

    self,

        logger.info(f"🔍 RAG found {len(results)} trips")

        # LEVEL 2~4: Fallback
        if len(results) == 0 and use_fallback:
            logger.warning(f"⚠️ No RAG results, trying fallback...")
            fallback_results = self._fallback_search(query, country_code, region1_idx, limit)
            return fallback_results

        return results

    except Exception as e:
        logger.error(f"❌ RAG search failed: {e}")
        # 예외 발생 시에도 Fallback 시도
        if use_fallback:

def _fallback_search(
    self,
    query: str,
    country_code: Optional[int],
    region1_idx: Optional[int],
    limit: int
) -> List[Dict]:
    """다단계 Fallback 검색"""

    results = []

    # LEVEL 2: YouTube Data API
    youtube_results = self._search_youtube_api(query, limit)
    if youtube_results:
        results.extend(youtube_results)
        logger.info(f"✅ YouTube API returned {len(youtube_results)} results")

    # LEVEL 3: Naver Blog (아직 부족하면)
    if len(results) < limit:
        naver_results = self._search_naver_blog(query, limit - len(results))
        if naver_results:
            results.extend(naver_results)
            logger.info(f"✅ Naver Blog returned {len(naver_results)} results")

    # LEVEL 4: GPT-4 생성 (최후의 수단)
    if len(results) == 0:
        gpt_results = self._generate_gpt_recommendations(query, limit)
        if gpt_results:
            results.extend(gpt_results)
            logger.info(f"✅ GPT-4 generated {len(gpt_results)} recommendations")

    return results[:limit]

## 요약

### ✅ 구현 완료

1. **4단계 Fallback 전략**
   - Level 1: RAG Database (pgvector) - 최우선
   - Level 2: YouTube Data API - 실시간 검색
   - Level 3: Naver Blog API - 블로그 후기
   - Level 4: GPT-4 Generated - 최후의 수단

2. **자동 Fallback**
   - RAG 결과 없으면 자동으로 다음 단계 시도
   - 예외 발생 시에도 Fallback 작동

3. **출처 표시**
   - 모든 결과에 "source" 필드 추가
   - 사용자가 정보 신뢰도 판단 가능

### 🎯 효과

- **항상 응답 가능**: RAG DB 비어있어도 OK
- **점진적 개선**: 데이터 쌓이면 자동으로 품질 향상
- **비용 최적화**: 무료/저렴한 API 우선
- **장애 복원력**: 하나 실패해도 다른 방법 시도
