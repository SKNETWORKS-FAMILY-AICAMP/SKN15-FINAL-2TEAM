# 여행 플래너 에이전트 프롬프트 구조도

## 📋 전체 구조 개요

```
┌─────────────────────────────────────────────────────────────┐
│                   Travel Planner Agent                      │
│                   (여행 플래너 AI 비서)                       │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
        ┌───────────────────────────────────────┐
        │   System Prompt (시스템 프롬프트)      │
        │   - 역할 정의                          │
        │   - 도구 목록                          │
        │   - 규칙 및 가이드                     │
        └───────────────────────────────────────┘
                            │
        ┌───────────────────┴───────────────────┐
        │                                       │
        ▼                                       ▼
┌───────────────┐                     ┌────────────────┐
│  Context      │                     │  Tools (15개)  │
│  (컨텍스트)    │                     │  (도구)         │
│               │                     │                │
│ • Trip ID     │                     │ 📊 조회 (1)    │
│ • Room ID     │                     │ 🏷️ 정보수정(2) │
│ • 현재연도/월  │                     │ 📍 일정관리(4)  │
│               │                     │ 🗑️ 삭제 (2)    │
└───────────────┘                     │ 🔍 검색 (5)    │
                                      │ ✨ AI추천 (1)  │
                                      └────────────────┘
```

---

## 🎯 1. 역할 정의 (Role Definition)

```
┌──────────────────────────────────────────────────┐
│           전문 여행 플래너 비서                    │
├──────────────────────────────────────────────────┤
│                                                  │
│  1️⃣  사용자들의 여행 계획을 도와주기              │
│  2️⃣  일정에 장소를 추가/수정/삭제하기             │
│  3️⃣  여행지 정보 제공하기                        │
│  4️⃣  최적의 여행 루트 제안하기                    │
│  5️⃣  사용자의 모든 대화를 기억하고 맥락을 이해하기 │
│                                                  │
└──────────────────────────────────────────────────┘
```

## 🛠️ 2. 도구 (Tools) 분류

### 📊 조회 (1개)

```
get_planner_info
    ↓
[현재 플래너 정보 조회]
    ↓
여행 정보, 일정, 장소 목록 반환
```

### 🏷️ 여행 정보 수정 (2개)

```
update_trip_info                update_trip_dates
    ↓                                ↓
[제목/인원/국가/지역 변경]      [날짜 변경 + Day 자동생성]
    ↓                                ↓
여행 기본 정보 업데이트          날짜 범위에 맞춰 Day 생성
```

**날짜 처리 로직:**
```
사용자 입력: "28일에서 30일로"
    ↓
현재 연도/월 가져오기: 2025년 11월
    ↓
변환: "2025-11-28" ~ "2025-11-30"
    ↓
update_trip_dates 실행
```

### 📍 일정 추가/수정 (4개)

```
add_place_to_day        update_schedule
    ↓                       ↓
[특정 일차에 장소 추가]    [일정 수정]
    ↓                       ↓
새 일정 생성              장소명/시간/메모 변경

move_schedule           reorder_schedule
    ↓                       ↓
[다른 날짜로 이동]        [순서 변경]
    ↓                       ↓
Day 간 일정 이동         같은 Day 내 순서 조정
```

### 🗑️ 일정 삭제 (2개)

```
delete_schedule         delete_all_schedules
    ↓                       ↓
[특정 장소 삭제]          [일차/전체 일정 삭제]
    ↓                       ↓
하나의 일정 제거         여러 일정 한번에 제거
```

### 🔍 장소 검색 (5개)

```
search_place            get_place_details
    ↓                       ↓
[DB + 카카오맵 검색]      [특정 장소 상세 정보]
    ↓                       ↓
평점/좌표/카테고리       주소/전화번호/영업시간

search_nearby           recommend_places
    ↓                       ↓
[주변 장소 검색]          [인기 장소 추천]
    ↓                       ↓
위도/경도 기반 검색      지역/카테고리 필터

search_and_show_on_map
    ↓
[UI 지도에서 검색]
    ↓
지도 인터페이스 열기
```

### ✨ AI 추천 (RAG, 1개)

```
recommend_similar_trips
    ↓
[실제 여행 데이터 기반 추천]
    ↓
┌─────────────────────┐
│   사용자 질문       │
│ "서울 여행 추천해줘" │
└─────────────────────┘
         ↓
┌─────────────────────┐
│  OpenAI Embedding   │
│  (벡터 변환)        │
└─────────────────────┘
         ↓
┌─────────────────────┐
│  pgvector 검색      │
│  (유사도 계산)      │
└─────────────────────┘
         ↓
┌─────────────────────┐
│  TripCourseEmbedding│
│  (DB에서 가져오기)   │
└─────────────────────┘
         ↓
┌─────────────────────┐
│  실제 여행 경로     │
│  - 유튜브 영상      │
│  - 블로그 포스트    │
│  - 구체적 일정      │
└─────────────────────┘
```

## 📝 3. 중요 규칙 (Rules)

```
┌─────────────────────────────────────────────────┐
│              규칙 실행 순서                      │
├─────────────────────────────────────────────────┤
│                                                 │
│  1️⃣  get_planner_info로 현재 일정 확인         │
│         ↓                                       │
│  2️⃣  search_place로 장소명 확인                │
│         ↓                                       │
│  3️⃣  도구 실행 (추가/수정/삭제)                │
│         ↓                                       │
│  4️⃣  결과를 명확하게 사용자에게 알림            │
│                                                 │
└─────────────────────────────────────────────────┘
```

**특수 규칙 - 날짜 처리:**
```
┌──────────────────────────────────────────────┐
│         날짜 입력 패턴 처리                   │
├──────────────────────────────────────────────┤
│                                              │
│  입력: "28일"                                │
│    → 변환: "{current_year}-{current_month}-28" │
│                                              │
│  입력: "1월 15일"                            │
│    → 변환: "{current_year}-01-15"            │
│                                              │
│  입력: "2025-11-10"                          │
│    → 그대로 사용                             │
│                                              │
└──────────────────────────────────────────────┘
```

## 🔄 4. 사용자 요청 처리 플로우

### Case 1: 여행지 추천 요청

```
사용자: "어디갈지 추천해줘"
    ↓
┌────────────────────────┐
│ 1. get_planner_info    │  ← 현재 여행 정보 확인
└────────────────────────┘
    ↓
┌────────────────────────┐
│ 2. recommend_similar_  │  ← RAG 기반 실제 여행 경로 추천
│    trips               │
└────────────────────────┘
    ↓
┌────────────────────────┐
│ 3. recommend_places    │  ← (필요시) 인기 장소 추가 추천
└────────────────────────┘
    ↓
사용자에게 결과 제공
```

### Case 2: 장소 추가 요청

```
사용자: "경복궁 1일차에 추가해줘"
    ↓
┌────────────────────────┐
│ 1. get_planner_info    │  ← 현재 일정 확인
└────────────────────────┘
    ↓
┌────────────────────────┐
│ 2. search_place        │  ← "경복궁" 정확한 정보 검색
│    (query="경복궁")     │
└────────────────────────┘
    ↓
┌────────────────────────┐
│ 3. add_place_to_day    │  ← 1일차에 추가
│    (day_no=1)          │
└────────────────────────┘
    ↓
사용자에게 완료 알림
```

### Case 3: 날짜 변경 요청

```
사용자: "11월 10일부터 13일로 바꿔줘"
    ↓
┌────────────────────────┐
│ 날짜 파싱              │
│ "11월 10일" → 2025-11-10 │
│ "13일" → 2025-11-13     │
└────────────────────────┘
    ↓
┌────────────────────────┐
│ update_trip_dates      │  ← 날짜 변경 + Day 자동 생성
│ (start: 2025-11-10,    │
│  end: 2025-11-13)      │
└────────────────────────┘
    ↓
사용자에게 변경 완료 알림
```

## 🌐 5. 전체 아키텍처

```
┌────────────────────────────────────────────────────────────┐
│                      사용자 (User)                          │
└────────────────────┬───────────────────────────────────────┘
                     │
                     │ "경복궁 추가해줘"

                     │
                     ↓

│           TravelPlannerAgent (LangChain Agent)             │
│  ┌──────────────────────────────────────────────────────┐ │
│  │  System Prompt (v1.py)                               │ │
│  │  - 역할, 도구, 규칙                                   │ │
│  │  - 동적 연도/월 주입                                  │ │

│  ┌──────────────────────────────────────────────────────┐ │
│  │  ChatOpenAI (GPT-4 Turbo)                            │ │
│  │  - Model: {CHAT_AGENT_MODEL}                         │ │
│  │  - Temperature: {CHAT_AGENT_TEMPERATURE}             │ │
│  └──────────────────────────────────────────────────────┘ │
│  ┌──────────────────────────────────────────────────────┐ │
│  │  ConversationBufferMemory                            │ │
│  │  - 대화 기억                                          │ │
│  └──────────────────────────────────────────────────────┘ │
│  ┌──────────────────────────────────────────────────────┐ │
│  │  Tools (15개)                                        │ │
│  │  - 조회, 수정, 검색, 추천...                          │ │
│  └──────────────────────────────────────────────────────┘ │
└────────────────────┬───────────────────────────────────────┘
                     │
                     │ (도구 실행)
                     ↓
┌────────────────────────────────────────────────────────────┐
│                  Django Models & APIs                       │
│  ┌─────────────┐  ┌─────────────┐  ┌──────────────┐       │
│  │  TripPlan   │  │   Place     │  │  TripCourse  │       │
│  │  TripDay    │  │   (Kakao)   │  │  Embedding   │       │
│  │  TripItem   │  │             │  │  (pgvector)  │       │
│  └─────────────┘  └─────────────┘  └──────────────┘       │
└────────────────────┬───────────────────────────────────────┘
                     │
                     ↓
┌────────────────────────────────────────────────────────────┐
│                   PostgreSQL + pgvector                     │
│  - 여행 데이터                                               │
│  - 벡터 임베딩 (1536 차원)                                  │
└────────────────────────────────────────────────────────────┘
```

## 📊 6. 프롬프트 버전 관리

```
prompts/
├── __init__.py          # 버전 선택 로더
│   ├── CURRENT_VERSION = "v1"
│   └── get_system_prompt(trip_id, room_id, version=None)
│
├── v1.py               # 버전 1 (현재)
│   ├── get_system_prompt(trip_id, room_id)
│   └── 동적 연도/월 주입
│
├── v2.py               # 버전 2 (예정)
│   └── 새로운 프롬프트...
│
├── README.md           # 사용 가이드
└── STRUCTURE.md        # 이 문서
```

**버전 전환:**
```python
# 현재 버전 사용
prompt = get_system_prompt(trip_id=123, room_id=456)

# 특정 버전 사용
prompt = get_system_prompt(trip_id=123, room_id=456, version="v1")
```

## 📈 8. 로깅 & 분석

```
사용자 메시지
    ↓
Agent 실행 (시작 시간 기록)
    ↓
도구 사용 추적
    ↓
응답 생성
    ↓
ChatRequest 테이블에 저장
    ├── user_message (전체 텍스트)
    ├── agent_response (전체 텍스트)
    ├── tools_used (JSON 배열)
    ├── execution_time_ms (실행 시간)
    ├── request_type (분류)
    └── success (성공 여부)
```

**분석 가능 데이터:**
- 가장 많이 사용되는 도구
- 평균 응답 시간
- 성공/실패율
- 사용자 요청 패턴
